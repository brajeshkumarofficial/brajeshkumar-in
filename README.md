# BrajeshKumar.in

Static first version of the Brajesh Kumar professional website.

## Structure
- Public professional profile
- Research
- Publications
- Education
- ChartRobo
- Contact
- Regulatory Information
- Privacy Policy
- Terms & Conditions

## Important
The regulatory page deliberately does not claim current SEBI registration.
Premium research/client login is not activated in this static version.

## Local preview
Open `index.html` in a browser.

## Future
Add a separate backend for authenticated premium research, private image storage,
subscriptions, client entitlements and admin publishing only after the applicable
regulatory/compliance requirements are finalized.
